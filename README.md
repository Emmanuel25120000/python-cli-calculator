CLI Calculator
A simple command-line calculator built in Python. Supports basic arithmetic operations with input validation and a continuous menu-driven loop.
Features
Add, Subtract, Multiply, Divide, Power, Modulo
Handles invalid input (non-numeric entries, division/modulo by zero)
Clean, modular code structure — each operation is its own function
How to run
python calculator.py

Then follow the on-screen menu to pick an operation and enter two numbers.
Example
=== CLI Calculator ===

1. Add (+)

2. Subtract (-)

3. Multiply (*)

4. Divide (/)

5. Power (^)

6. Modulo (%)

Q. Quit

Choose an operation: 1

Enter first number: 4

Enter second number: 5

Result: 4.0 + 5.0 = 9.0
